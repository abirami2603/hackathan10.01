# ☁️ Cloud Service Management
### Coders Club – Saturday Hackathon | Team 13

---

## 📌 Project Overview

A web-based **Cloud Service Management Dashboard** that allows users to:
- Add and remove cloud services
- Start and stop services
- Monitor real-time resource usage (CPU, Memory, Storage)
- View activity logs

---

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| HTML5 | Structure |
| CSS3 | Styling & Animations |
| JavaScript | Logic & Interactivity |

---

## 🚀 How to Run

1. Download or clone this repository
2. Open `index.html` in any web browser
3. No installation required!

---

## ✨ Features

- ✅ Add cloud services (Compute, Storage, Database, Network, Security)
- ✅ Start / Stop services
- ✅ Delete services
- ✅ Live resource usage bars (CPU, Memory, Storage)
- ✅ Activity log with timestamps
- ✅ Real-time stats dashboard
